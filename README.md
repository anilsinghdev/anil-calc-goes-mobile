# Anil's Simple Calc

Build a responsive calculator using only HTML, CSS and JavaScript.



Requirements:



- Modern, clean mobile-friendly UI.

- Display screen for input/result.

- Buttons: 0–9, +, −, ×, ÷, %, decimal, =, AC, backspace.

- Correct arithmetic calculations and error handling.

- Keyboard support.

- Show calculator name: Anil Calculator.

- Add a small footer: Made by Anil.

- Use no unnecessary libraries or backend.

- Keep the code simple, fast and lightweight.

- Make all buttons fully functional.

- Optimize for mobile.



Important: I want to publish it online. Make the project ready for deployment and use Anil Calculator as the website/app name.
